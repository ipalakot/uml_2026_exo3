#Git branch
La commande git branch peut être utilisée pour répertorier, créer ou supprimer des branches. 
    ## Pour répertorier toutes les branches présentes dans le dépôt, utilisez:
        git branch 
        git branch –v –a (pour le remote) 
    
    ## Creation de branch
        git branch Dev


## Git Switch
    la commande Switch permet de changer de branche sur Git
    
    ## Aller sur la branch dev
        git switch Dev
